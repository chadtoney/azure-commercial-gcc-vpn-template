# Contributing

## Workflow

1. Create a feature branch.
2. Make focused changes with clear commit messages.
3. Validate Bicep and script behavior locally.
4. Update documentation when behavior changes.
5. Open a pull request with test evidence.

## Required Checks

- No sensitive information in tracked files.
- Parameter examples remain sanitized.
- Deployment commands in README still work.
- Validation runbook steps remain accurate.

## Style

- Keep templates and scripts simple and explicit.
- Prefer clear parameter names over shorthand.
- Keep docs concise and operationally useful.
